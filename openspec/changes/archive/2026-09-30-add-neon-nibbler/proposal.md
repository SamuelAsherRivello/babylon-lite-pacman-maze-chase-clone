# Proposal

## Why

The empty template needs a complete arcade experience. Neon Nibbler turns the supplied maze-chase brief into an original landscape game that is readable, responsive, replayable, and published for browser play.

## What Changes

- Add three original mazes, buffered grid movement, four enemy personalities, pellet scoring, power effects, lives, and victory.
- Add keyboard and touch input, title/ready/pause/result screens, original procedural pixel artwork and synthesized audio.
- Add a responsive landscape cabinet with Babylon Lite WebGPU rendering and clear unsupported-device recovery.
- Add simulation and browser checks, documentation, GitHub release, and Pages delivery.

## Capabilities

### New Capabilities
- `maze-chase`: Maze navigation, pursuit, collectibles, scoring, lives, and progression.
- `arcade-presentation`: Landscape rendering, controls, audio, HUD, persistence, and recovery.

### Modified Capabilities
None.

## Impact

Application files under project-name/, npm dependencies and checks, release/Pages workflows, README and documentation. No multiplayer service. The latest user instruction selects landscape rather than the skill's portrait default.
